Кожна лабораторна робота лежить в окремій папці і самодостатня: свій код, `docker-compose.yml` або маніфести, генератор, результати і звіт `REPORT.md`. Стенд лаби запускається з її папки.

| Робота | Папка | Гілка | Тема |
|---|---|---|---|
| ЛР 1 | [`lab1/`](lab1/) | [`lab1`](../../tree/lab1) | CRUD-сервіс `/telemed-sessions`: FastAPI + PostgreSQL у Docker Compose, балансування nginx, навантаження у відкритому контурі |
| ЛР 2 | [`lab2/`](lab2/) | [`lab2`](../../tree/lab2) | Метрики Prometheus, коректна зупинка, ступінчасте навантаження на 1–4 екземплярах, закон масштабованості |
| ЛР 3 | [`lab3/`](lab3/) | [`lab3`](../../tree/lab3) | Той самий сервіс у кластері kind: StatefulSet бази, моніторинг, HPA і порівняння з фіксованою кількістю реплік |

Здані версії позначені тегами `labN-vK`, наприклад `lab1-v2` і `lab2-v1`. Подивитися здану версію: `git checkout lab1-v2`.
